# Project Goal:
- User inputs key signature, bass note, and additional notes
- Project outputs a name for the chord based on the key and other known data
# MVP Scope: 
- Take in a key signature, bass note and up to 4 additional notes from the user
- Determine chord qualities based on the notes
- Output likely chord and relative chord to the key
# Future Plans: 
- Multiple possible names for each chord
- Sounds of each note being typed in
- Whole chord played at end
# Tech Stack:
1. I will be writing in Java
2. I will need to import libraries to create a usable GUI and potentially libraries for sounds.
3. I can use a plain text file to store data.
4. I don't need to pull data from an external source.
